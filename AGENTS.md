# Instrucoes do projeto

- Nao usar `gpt-image-2` em nenhuma parte deste projeto.
- Nao usar geracao de imagem da OpenAI.
- Nao configurar ferramentas de imagem em `tools`.
- Nao adicionar chamadas como `image_generation`, `images.generate` ou qualquer image tool.
- Quando precisar sugerir imagens, logos ou layout, usar apenas texto, CSS, HTML, arquivos locais ja existentes ou orientacoes manuais.
- Este app deve funcionar sem nenhuma dependencia de geracao de imagem.
